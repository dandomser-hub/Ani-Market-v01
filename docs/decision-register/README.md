# Ani Market Decision Register

Artifact 0 is the authoritative detailed Decision Register.

The decision-complete baseline contains:
- approved detailed decisions for Chunks 1-7 using `C1.xx-C7.xx`;
- all approved Chunk 8 rules using `R8.01-R8.15`;
- decision/approval gates using `DG-xx`;
- implementation provenance for Gate 1, Gate 2A, 2B-1 and 2B-2;
- documentation controls using `GOV-xx`;
- explicit Pending Deliberation state for Chunks 9-15.

The formal Decision Traceability Matrix cross-references each decision to requirements, process, data, screens/UX, architecture, QA and implementation gate where applicable.

No implementation status may be inferred solely from approval status.
